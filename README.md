# Traza

Herramienta de trazas de Python para ayudantías. Incluye Coyotes y gallinas, La racha más larga, Plantas por regar y El máximo de Collatz.

Sitio estático: publicar el contenido de esta carpeta con index.html en la raíz. No requiere instalación ni compilación. Los recursos usan rutas relativas compatibles con un sitio de proyecto de GitHub Pages.

El tema oscuro es predeterminado. El selector de tema recuerda la preferencia en el navegador.
